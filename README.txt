TechArena Gas Pipeline — временная заглушка для KPI

1. Распакуй все содержимое архива в корень своего Go-проекта,
   рядом с pipe_strategy.go и contracts.go.
   В папке testdata/kpi_open появятся 15 входных тестов.

2. Запусти из корня проекта:
   go test -run '^TestOpenKPI$' -v -count=1 -timeout=3m

3. На экране будет таблица KPI по тестам для
   First Fit / Best Fit / Worst Fit и суммарные взвешенные очки.

Заглушка напрямую вызывает ClassicStrategy.ChoosePlacement и
самостоятельно имитирует траншею и PID. Настоящие Layout и Controller
не нужны. Для ускорения использует временное хранение свободных
интервалов на кучах (heaps). Реализует размещение только с левого
края каждого интервала, как решено в команде.

Важно: это симуляция на 15 открытых тестах, а не официальный runner.
Кандидаты — лучшие First, Best и Worst среди всех текущих свободных
интервалов, поэтому результат может отличаться от реального Layout,
если он передает другой набор кандидатов.

Для другой папки с 15 *.in тестами можно запустить так:
   TECHAREA_TESTS=tests go test -run '^TestOpenKPI$' -v -count=1

Файл kpi_stub_test.go — только для тестирования, он не войдет
в итоговый исполняемый файл после go build. Если вы захотите
убрать заглушку, достаточно удалить kpi_stub_test.go.
